# 🛒 Amazon Clone

A responsive **Amazon Clone** built using **HTML, CSS, and JavaScript**.
This project recreates the basic e-commerce interface and functionality of Amazon for learning and practicing frontend development.

## 📋 Prerequisites

Before running the project, make sure you have:

* A modern web browser such as:

  * Google Chrome
  * Microsoft Edge
  * Mozilla Firefox
* **VS Code** or another code editor *(recommended)*
* **Git** *(optional, only required if you want to clone the repository)*
* **Live Server** extension for VS Code *(optional but recommended)*

> No Node.js, npm, or backend server is required for this project.

## ⚙️ Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd Amazon-Clone
```

### 3. Open the project

Open the project folder in **VS Code** or your preferred code editor.

## ▶️ Run Options

### Option 1: Open Directly in Browser

Simply double-click:

```text
index.html
```

The project will open directly in your default browser.

### Option 2: Using VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The project will then be available at a local URL such as:

```text
http://127.0.0.1:5500/
```

### Option 3: Using a Local Server

If you already have a local development server configured, serve the project directory and open the provided local URL in your browser.
